# **App Name**: InstaFocus

## Core Features:

- Main Feed Display: Display of main feed with posts from followed accounts. Posts should include images, captions, and like/comment counts.
- Post Detail View: Display individual posts, including the full-size image/video, caption, comments, like count, and options to like/comment.
- Post Creation and Upload: Allow users to upload images/videos, add captions, tag locations, and post content to their feed.
- Follow/Unfollow Feature: Allow users to follow and unfollow other users.
- Profile Display: Display of user profiles, including posts, followers, following, bio, and profile picture.
- Caption Generation: Generative AI caption tool that provides caption suggestions based on image analysis.

## Style Guidelines:

- Primary color: A vibrant cerulean blue (#2AB0ED) evokes a sense of calm connectivity.
- Background color: A very light cool grey (#F2F4F7) provides a neutral backdrop, allowing the content to stand out.
- Accent color: A vivid violet (#833AB4) provides highlights, drawing user attention to calls to action.
- Clean, sans-serif font for all text elements to ensure readability and modern look.
- Simple, line-based icons for navigation and actions to maintain a consistent and clean aesthetic.
- Use of a grid-based layout to create a structured and visually appealing content presentation.
- Subtle fade-in and slide-up animations for content loading and transitions.
